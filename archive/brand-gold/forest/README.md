# WYRD Gold Forest Archive

This directory preserves the former gold visual assets for the `Forest` home screen.

They are retained as design history and may still be displayed by legacy documentation. Do not connect these files to the active application. The current Forest screen uses the monochrome silver artwork in:

`assets/images/forest-home/silver/`

Archived assets:

- `f-hero2.png` and `fern-hero2.png` - former hero card frame and fern;
- `moon.png`, `leaves-fall.png`, `moth2.png`, `tracks.png`, `acorn.png` - former gold navigation artwork.

`assets/images/forest-home/bg.jpg` is intentionally not archived yet. It remains a shared runtime dependency for Settings and Spirit Book and must move only when those screens receive their own silver migration pass.
