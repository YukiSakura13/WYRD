# WYRD — Главный экран (спецификация 1:1)

## Задача
Воспроизвести главный экран приложения **1:1** по вёрстке, типографике, цветам, композиции карточек и микроанимациям, со следующими адаптациями:
- Экран **скроллится по вертикали** (контент выше видовой области телефона).
- Реализовать по своей архитектуре, но с тем же визуальным результатом.
- Использовать приложенные иллюстрации как есть — это финальный арт, не референс.

## Холст (референс макета)
Карточка-телефон **393 × 852px**, скругление `44px`, подложка снаружи `#0a0b0d`. В проде — full-screen на устройстве. Внутри — вертикальный скролл без видимого скроллбара (`scrollbar-width:none`, `::-webkit-scrollbar{width:0}`).

## Фон экрана (статичный, под скроллящимся контентом)
Два слоя, `position:fixed`-подобно (сидят под скроллом, не двигаются вместе с контентом):
1. **Тональные пятна** — `radial-gradient(120% 60% at 50% -6%, rgba(30,34,45,.42), transparent 56%), radial-gradient(90% 50% at 50% 34%, rgba(16,18,26,.5), transparent 72%), linear-gradient(180deg, #0c0d11 0%, #08090c 100%)`.
2. **Звёздная пыль вверху** — 6 точек радиальными градиентами (~1–1.4px) в диапазоне `top: 2.5–6%`, цвет `rgba(240,232,216, .5–.7)`, вся группа мерцает: `animation: wyrdTw 5s ease-in-out infinite` (`@keyframes wyrdTw {0%,100%{opacity:.4} 50%{opacity:1}}`).
Верх экрана дополнительно смягчён узкой (`30px`) полосой fade: `linear-gradient(180deg, #0b0c0f, transparent)` — чтобы контент уходил под неё при скролле.

## Шрифты
Google Fonts: **IM Fell English** (только слово WYRD) + **Cormorant Garamond** (400/500/600) для всего остального + **Forum** для заголовков карточек (uppercase, letter-spacing).

## Палитра
- Кость/текст: `#F3ECDD`, `#EFEADC`, `rgba(210,212,210,.6–.66)` (подписи курсивом)
- Серебро линий/обводок: `rgba(228,224,212,.4–.5)`, `rgba(232,228,216,.5)`, hover `rgba(244,238,224,.85)`
- Тёмный фон карточек: `#08090c` / `#000`
- **Без золота нигде.**

## Структура сверху вниз (padding контейнера `0 24px 40px`, весь стек `text-align:center` где заголовки)

### 1. Шапка — иконки (padding-top: 52px)
`display:flex; justify-content:space-between`. Два одинаковых круглых стеклянных значка:
- **52×52px**, `border-radius:50%`, `background:rgba(12,14,18,.5)`, `border:1px solid rgba(228,224,212,.4)`, `box-shadow:0 8px 20px rgba(0,0,0,.42)`.
- **Слева — аватар/профиль**: SVG-иконка "человек" (голова-круг + плечи-дуга), `stroke:rgba(228,224,212,.72)`, `stroke-width:1.1`, без заливки.
- **Справа — настройки**: SVG-иконка **шестерёнка** (не солнце!) — стандартная 8-зубцовая шестерня с отверстием в центре, тот же серебристый `stroke`, `stroke-width:1.1`, `stroke-linecap/linejoin:round`.
- Обе иконки — кнопки (`cursor:pointer`), тап-зона — вся окружность 52px (> Apple HIG 44pt минимума).

### 2. Вордмарк (margin-top: 22px, по центру)
1. **WYRD** — шрифт `IM Fell English`, `text-transform:uppercase`, `letter-spacing:.2em`, `font-size:38px`, `line-height:1`, цвет `#F3ECDD`, `text-indent:.2em`.
2. Тонкая черта под ней: `width:96px; height:1px`, `margin:13px auto 0`, `linear-gradient(90deg, transparent, rgba(238,232,220,.5), transparent)`.
3. Подпись «Оракул духов леса» — `Cormorant Garamond` 500, uppercase, `letter-spacing:.32em`, `font-size:12px`, цвет `rgba(216,218,216,.64)`, `margin-top:11px`.

### 3. Герой — «Раскрыть карту» (margin-top: 30px)
Компактная **центрированная** карточка-портал (НЕ на всю ширину экрана): `width:224px; margin:0 auto`, `aspect-ratio:3/4`, `border-radius:18px`, `overflow:hidden`.
- Контейнер: `background:#08090c`, `border:1px solid rgba(232,228,216,.5)`, `box-shadow:0 18px 44px rgba(0,0,0,.6)`; hover → `border-color:rgba(244,238,224,.85)`.
- **Ореол-«дыхание»** позади арта: круг `78%×66%` контейнера, по центру со сдвигом (`left:50%;top:44%`), `radial-gradient(circle, rgba(224,228,236,.16), transparent 66%)`, анимация `wyrdHalo 7s ease-in-out infinite` (`@keyframes {0%,100%{opacity:.5; transform:scale(1)} 50%{opacity:.92; transform:scale(1.05)}}`).
- Картинка `raven-arch.png` (ворон в готической арке из веток и чертополоха, гравюра серебром на чёрном) — `object-fit:cover`, поверх ореола.
- Лёгкая внутренняя виньетка: `box-shadow: inset 0 0 60px 12px rgba(6,7,10,.5)`.
- Вся карточка целиком — кликабельная кнопка.
- **Подпись НИЖЕ карточки** (не поверх картинки!), `margin-top:14px`, по центру:
  - «Раскрыть карту» — `Forum`, uppercase, `letter-spacing:.16em`, `font-size:23px`, цвет `#EFEADC`.
  - «карта дня · гадание» — `Cormorant Garamond` italic, `font-size:15px`, цвет `rgba(210,212,210,.66)`.

### 4. «Лунный день» (margin-top: 34px)
Широкая карточка на всю ширину контента, `aspect-ratio:16/9`, `border-radius:16px`.
- Тот же паттерн контейнера: `background:#08090c`, `border:1px solid rgba(232,228,216,.5)`, `box-shadow:0 12px 30px rgba(0,0,0,.5)`; hover → `border-color:rgba(244,238,224,.85); box-shadow:0 12px 34px rgba(0,0,0,.6)` (переход `.25s`).
- Картинка `moon-phases-dotwork.png` (дуга лунных фаз, дотворк-гравюра серебром на чёрном), `object-fit:cover`.
- Подпись ниже, `margin-top:13px`: «Лунный день» (`Forum` uppercase `letter-spacing:.14em` `19px` `#EFEADC`) + «оракул по фазе луны» (`Cormorant Garamond` italic `14px` `rgba(210,212,210,.64)`).

### 5. Пара карточек «Нет или да» / «Образы ночи» (margin-top: 34px)
`display:grid; grid-template-columns:1fr 1fr; gap:18px`. Каждая карточка:
- `aspect-ratio:3/4`, `border-radius:16px`, тот же контейнер-стиль, что у «Лунного дня» (обводка/тень/hover идентичны).
- Картинки: `poppy-frame.png` (мак в двойной серебряной рамке с чертополохом по углам) и `moth-frame.png` (мотылёк, та же рамка) — `object-fit:cover`.
- **Мерцающие точки поверх картинки** (внутри контейнера, `pointer-events:none`): ~15–26 круглых точек диаметром 2–3px, цвет `rgba(226,222,210, .7–.9)`, разбросаны **по всему чёрному полю карточки** (не кучей в одном углу — координаты `left`/`top` разбросаны от 2% до 92% по X и от 4% до 75% по Y), каждая точка — свой `animation-delay` (0.1–4.4s) и своя длительность (3.6–4.6s), общая анимация `wyrdTw` (та же, что у звёзд фона).
- Подписи ниже, `margin-top:11px`: заголовок (`Forum` uppercase `16px` `#EFEADC`) + курсивная подпись (`13px` `rgba(210,212,210,.6)`) — «короткий знак» / «сонник».

### 6. «Следы в лесу» (margin-top: 34px)
Широкая карточка `aspect-ratio:16/9`, тот же стиль контейнера, `background:#000`.
- Картинка `hare-forest.png` (чёрный заяц-дух с рогами-веточками и светящимся глазом, бежит сквозь туманный лунный лес), `object-fit:cover`.
- Подпись ниже: «Следы в лесу» + «твоя история и дары».

### 7. «История духов леса» (margin-top: 32px)
Широкая карточка `aspect-ratio:16/9`, тот же стиль контейнера, `background:#000`.
- Картинка `history-pattern.png` (плотный орнамент — переплетённые ветви, чертополох, летучие мыши — символ «сплетённой истории»), `object-fit:cover`.
- Подпись ниже: «История духов леса» + «сказание о мире Wyrd · пять глав».

## Общий паттерн карточки (повторяется у пунктов 4–7)
```
border-radius: 16px;
overflow: hidden;
border: 1px solid rgba(232,228,216,.5);
box-shadow: 0 12px 30px rgba(0,0,0,.5);
cursor: pointer;
transition: box-shadow .25s, border-color .25s;
/* hover */
border-color: rgba(244,238,224,.85);
box-shadow: 0 12px 34px rgba(0,0,0,.6);
```
Герой-карточка (пункт 3) использует тот же паттерн, но крупнее тень (`0 18px 44px`) и добавочный ореол-дыхание.

## Область нажатия
Каждая карточка целиком (картинка + рамка) — единая кнопка/ссылка; подпись под ней не кликабельна отдельно, но визуально принадлежит той же карточке (клик по подписи не обязателен, но не помешает). Минимальная сторона карточки всегда сильно больше 44pt — норму по площади нажатия соблюдать незачем проверять отдельно.
