# Archive

В этой папке лежат неиспользуемые production-версией артефакты:

- старые визуальные эксперименты;
- CSS-прототипы;
- вспомогательные reference-файлы, если они ещё могут пригодиться как исторический контекст.

Основные разделы:

- `brand-gold/` — снятая с production золотая айдентика и её документация;
- `brand-silver-source/` — утверждённые исходники и review-страницы, которые
  больше не являются активными рабочими поверхностями;
- `docs/historical-audits/` — датированные аудиты вместе с их evidence;
- `docs/legacy-specs/` — старые ТЗ, чья актуальная механика перенесена в
  канонические документы;
- `docs/qa/` и `docs/status-snapshots/` — завершённые QA-журналы и разовые
  статусные снимки.

Правило:

- production-код не должен ссылаться на файлы из `archive/`;
- материалы в `archive/` не являются источником истины;
- если файл снова нужен приложению, его нужно вернуть в живую структуру проекта осознанно, а не держать рядом "на всякий случай".
