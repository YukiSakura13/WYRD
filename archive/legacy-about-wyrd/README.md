# Legacy About WYRD page

This directory preserves the retired text-only `О WYRD / Книга леса` page introduced by YUK-132.

It is not part of the active application and must not be imported by production HTML, CSS, JavaScript, tests, or deployment workflows. The current story experience is `История духов леса`: the five-page illustrated `spirit-book` opened from the Forest screen.

Archived material:

- `index-with-legacy-page.html` — exact application entry snapshot before removal;
- `assets/css/about-wyrd.css` — retired scene styles;
- `assets/js/about-navigation.js` — retired hash router and return behavior;
- `docs/PUBLIC_LORE_COPY.md` — retired page copy contract;
- `scripts/` — retired smoke and validation scripts.
