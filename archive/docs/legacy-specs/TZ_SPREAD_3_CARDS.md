## Контекст

Этот экран открывается после нажатия кнопки `✦ РАСКРЫТЬ ТРИ КАРТЫ ✦` на экране расклада с 1 картой.

Карта №1 — та же карта, которую пользователь уже видел в раскладе на 1 карту. Она переходит как якорь.

Экран состоит из двух состояний:
- **Состояние A — Расклад** (основной экран): три карты в геометрии архетипа + Духи леса шепчут + CTA
- **Состояние B — Карта** (modal overlay): App Store-style раскрытие карты по тапу

Стандартный `screen-nav` проекта — не создавать отдельный.

```
[←]          WYRD
       ОРАКУЛ ДУХОВ ЛЕСА
```

- Левая: кнопка «назад» — возвращает на экран расклада 1 карты
- Центр: `WYRD`
- Правая: пусто

## Блок вопроса

Два состояния — одинаковые на всех трёх экранах (1 карта, 3 карты, 5 карт).

**Состояние A — вопрос задан:**

```
ТВОЙ ВОПРОС
│ Я хочу уволиться с работы...
```

**Состояние B — вопрос не задан:**

```
ТВОЙ ВОПРОС
│ Тайна приоткроется сама...
```

Оформление одинаковое в обоих состояниях:
- Метка `ТВОЙ ВОПРОС`: `font-size: 8px`, `letter-spacing: 2.5px`, `color: var(--gold)`, sans-serif
- Текст: `font-size: 13px`, `color: var(--text-muted)`, `font-style: italic`
- Левая граница: `2px solid var(--gold)`
- `background: rgba(0,0,0,0.22)`, `border-radius: 0 8px 8px 0`
- Текст вопроса обрезается на одной строке с `text-overflow: ellipsis` если слишком длинный
- Текст-заглушка «Тайна приоткроется сама...» не обрезается — он всегда короткий

## Зона расклада — три карты

### Геометрия определяется архетипом

Архетип вычисляется из вопроса пользователя через существующий `detectArchetype()` в `scoring.js`. Четыре варианта геометрии:

---

#### Архетип А — «Что происходит» / Вертикальная колонна

```
  [1]  ← якорь (крупнее)
   |
  [2]
   |
  [3]
```

Карты расположены по вертикали по центру экрана.
Карта №1 сверху, крупнее остальных.
Отступ между картами: 12px.

| Позиция | Роль |
|---|---|
| 1 — якорь | поверхность ситуации |
| 2 | скрытое |
| 3 | сдвиг |

---

#### Архетип Б — «Что будет» / Горизонтальный ряд, якорь в центре

```
[2] — [1] — [3]
       ↑
     якорь
```

Три карты в один горизонтальный ряд.
Карта №1 в центре, крупнее крайних.

| Позиция | Роль |
|---|---|
| 2 — слева | было |
| 1 — центр — якорь | сейчас |
| 3 — справа | исход |

---

#### Архетип В — «Что делать» / Перевёрнутый треугольник, якорь снизу

```
[2]     [3]
  \     /
   [1]       ← якорь
```

Карты 2 и 3 вверху по краям, карта 1 внизу по центру.
Карта №1 крупнее.

| Позиция | Роль |
|---|---|
| 2 — верх левый | что держит |
| 3 — верх правый | ресурс |
| 1 — низ центр — якорь | шаг |

---

#### Архетип Г — «Кто этот человек» / Треугольник острием вниз, якорь сверху

```
   [1]        ← якорь
  /   \
[2]   [3]
```

Карта №1 вверху по центру, карты 2 и 3 внизу по краям.
Карта №1 крупнее.

| Позиция | Роль |
|---|---|
| 1 — верх центр — якорь | сущность / ядро |
| 2 — низ левый | что движет |
| 3 — низ правый | скрытое |

---

### Визуал карт

**Все карты показываются лицом — иллюстрации видны сразу.** Рубашкой не показывать.

**Якорная карта №1:**
- Размер: на ~15–20% крупнее остальных карт
- `box-shadow: 0 0 12px rgba(201,168,76,0.35)`
- `border: 2px solid var(--gold)`

**Остальные карты (2 и 3):**
- Стандартный размер
- Стандартная рамка
- Никаких номеров, никаких меток

**Номера позиций на картах не показывать.** Иерархия читается через визуал — размер и рамка якорной карты.

**Область тапа каждой карты: минимум 44×44pt.**

---

### Анимация появления карт

1. Якорная карта №1 появляется первой: `fade-in + scale 0.95 → 1`, длительность `0.5s`
2. Пауза `~0.6s`
3. Карта №2: то же самое, задержка `0.6s` от старта
4. Карта №3: то же самое, задержка `1.0s` от старта

`easing: cubic-bezier(0.25, 0.46, 0.45, 0.94)`

---

### Состояния карты

| Состояние | Вид |
|---|---|
| Якорная — всегда | Крупнее + золотая акцентная рамка + свечение |
| Нетронутая | Стандартный вид |
| Активная (в момент тапа) | `box-shadow: 0 0 18px rgba(201,168,76,0.5)` |
| Просмотренная | Без изменений — не приглушать |

## Блок «Духи леса шепчут»

Располагается **сразу под зоной расклада**, до кнопок и CTA.

Блок использует тот же ритуальный принцип, что и `ТВОЙ ВОПРОС`: **тонкая золотая черта слева**, без карточки и тяжёлого контейнера.

**Текст:**

```
│ Духи леса шепчут:
│
│ Не всё сейчас открыто полностью.
│ Прошлый образ всё ещё кажется
│ убедительнее настоящего.
│ У тебя уже есть ключ.
│
│ Что в этом отражении
│ ты уже узнаёшь?
```

- Левая черта: `2px solid var(--gold)`, как в блоке `ТВОЙ ВОПРОС`
- «Духи леса шепчут:» — первая строка, `color: var(--gold)`, `font-style: normal`, `font-weight: 500`
- Текст — короткие смысловые строки, `font-style: italic`, `color: var(--text-primary)`
- Перед финальным вопросом нужен отдельный отступ
- Весь блок: `font-family: var(--display-font)`, `font-size: 14px`, `line-height: 1.8`
- Выравнивание: по левому краю
- `margin: 0 20px`, `padding-left: 12px`
- Никакой рамки, никакого фона, никакой подложки — только золотая черта

Текст строится функцией `buildPositionAwareOracleMessage` из `oracle-local.js`.
Голос не называет позиции карт. Говорит про человека и ситуацию через образы всех трёх карт как единой истории, но выводится не сплошным абзацем, а короткими смысловыми строками: 3 строки по картам + финальная строка/вопрос.

Финал текста меняется по архетипу:
- Архетип А → заканчивается вопросом-зеркалом
- Архетип Б → заканчивается знаком, утверждением о времени
- Архетип В → заканчивается командой
- Архетип Г → заканчивается предупреждением или вопросом

## CTA

**Текст-крючок** над кнопкой:

> *Ты уже многое знаешь. Но пять карт откроют то, что три не сказали...*

- `font-family: var(--display-font)`, `font-size: 13px`, `font-style: italic`
- `color: var(--text-muted)`, `text-align: center`
- `padding: 0 24px 20px`

**Основная кнопка:**

```
[ ✦ РАСКРЫТЬ ПЯТЬ КАРТ ✦ ]
```

- Переход к экрану расклада на 5 карт
- `background: var(--gold)`, тёмный текст, полная ширина с отступами `0 14px`
- `padding: 15px`, `border-radius: 8px`
- `font-size: 11px`, `letter-spacing: var(--tracking-ritual)`, `font-weight: 600`
- Цвет текста: `var(--color-bg-base)`

**Тихая ссылка под кнопкой:**

```
Задать новый вопрос
```

- Возврат к колоде, сброс сессии
- `color: var(--gold)`, `font-size: 12px`
- Без рамки, без фона
- `padding: 12px 0`, `text-align: center`
- Это `quiet gold link`: заметнее обычного текста, но тише основной золотой кнопки

## Состояние B — Modal card (App Store-style)

### Триггер

Тап на любую карту в раскладе → открывается modal overlay с деталями этой карты.

Экран расклада сохраняет scroll position, все карты, текст духов и завершённые анимации. Это не отдельный route.

### Анимация открытия

Карта визуально «расширяется» из своего места в раскладе:
- Expand transition из позиции карты в раскладе
- Плавный переход: `duration: 0.4s`, `cubic-bezier(0.32, 0.72, 0, 1)`
- Фоновое затемнение: `background: rgba(0,0,0,0.75)`, появляется одновременно

### Содержимое modal card (сверху вниз)

```
                            [×]

[иллюстрация карты — крупно]

   ✦ КЛЮЧЕВОЕ СЛОВО ПОЗИЦИИ ✦

       Название карты

   ─────── ПОСЛАНИЕ ───────
   Текст послания (2–3 предложения)

   ─────── ТЕНЬ ───────
   Текст тени (1 предложение)
```

**Кнопка закрытия:**
- Верхний правый угол
- Область тапа: минимум 44×44pt, визуально 28×28px круг
- `border: 0.5px solid rgba(255,255,255,0.15)`, иконка ×

**Ключевое слово позиции:**
- Берётся из `archetype-config.js` для текущего архетипа и номера позиции
- `font-size: 8px`, `letter-spacing: 3px`, `color: var(--gold)`, sans-serif, uppercase

**Иллюстрация:**
- Реальное изображение карты из assets
- `max-height: 45vh`, `object-fit: contain`
- Без рамки внутри modal

**Название карты:**
- `font-family: var(--display-font)`, `font-size: 22px`, `text-align: center`

**Послание:**
- `font-size: 15px`, `line-height: 1.75`, `text-align: center`, `padding: 0 28px`

**Тень:**
- `font-size: 13px`, `font-style: italic`
- `color: var(--text-muted)`, `text-align: center`, `padding: 0 32px`

### Закрытие

- Кнопка × сверху справа
- Тап на затемнённый фон
- `Escape` (для браузера)
- После закрытия — возврат к раскладу без потери состояния, без потери scroll position

### Навигация между картами

Свайпа между картами нет. Чтобы посмотреть другую карту — закрыть modal и выбрать другую в раскладе.

---

## Overflow

На корневом контейнере экрана: `overflow-x: hidden`.
Экран не должен «ездить» вправо-влево.

---

## Шеринг

Шеринга на экране расклада на 3 карты нет.
Кнопку «Поделиться» не добавлять.
Шеринг остаётся только на экране 1 карты.

---

## Что не делать

- Не показывать подписи позиций на картах в раскладе — они только внутри modal card
- Не нумеровать карты — ни цифрами, ни кружками
- Не приглушать просмотренные карты
- Не добавлять свайп между картами в modal
- Не использовать bottom sheet для просмотра карты — только App Store expansion
- Не добавлять шеринг на этот экран
- Не создавать отдельный route для просмотра карты
- Не выравнивать текст «Духи леса шепчут» по центру — только по левому краю
- Не оформлять «Духи леса шепчут» как карточку, рамку или панель с фоном — только левая золотая черта
