# WYRD — ТЗ: Экран расклада на 5 карт

**Версия:** 1.0  
**Статус:** Готово к передаче в Codex  
**Связанные документы:** `WYRD_LAYOUT_VISUAL.md`, `TZ_SPREAD_3_CARDS.md`, `archetype-config.js`

---

## Контекст

Этот экран открывается после нажатия кнопки `✦ РАСКРЫТЬ ПЯТЬ КАРТ ✦` на экране расклада с 3 картами.

Карта №1 — та же якорная карта, которую пользователь видел на экранах 1 и 3 карт. Она переходит как якорь.

Расклад на 5 карт — **финальный**. CTA к следующему раскладу нет.

Экран состоит из двух состояний:
- **Состояние A — Расклад** (основной экран): пять карт в геометрии архетипа + Духи леса шепчут + завершающий текст + CTA
- **Состояние B — Карта** (modal overlay): App Store-style раскрытие карты по тапу

---

## Хедер

Стандартный `screen-nav` проекта — не создавать отдельный.

```
[←]          WYRD
       ОРАКУЛ ДУХОВ ЛЕСА
```

- Левая: кнопка «назад» — возвращает на экран расклада 3 карты
- Центр: `WYRD`
- Правая: пусто

## Блок вопроса

Два состояния — одинаковые на всех трёх экранах (1 карта, 3 карты, 5 карт).

**Состояние A — вопрос задан:**

```
ТВОЙ ВОПРОС
│ Я хочу уволиться с работы...
```

**Состояние B — вопрос не задан:**

```
ТВОЙ ВОПРОС
│ Тайна приоткроется сама...
```

Оформление:
- Метка `ТВОЙ ВОПРОС`: `font-size: 8px`, `letter-spacing: 2.5px`, `color: var(--gold)`, sans-serif
- Текст: `font-size: 13px`, `color: var(--text-muted)`, `font-style: italic`
- Левая граница: `2px solid var(--gold)`
- `background: rgba(0,0,0,0.22)`, `border-radius: 0 8px 8px 0`
- Текст вопроса: `text-overflow: ellipsis`, одна строка
- Текст-заглушка не обрезается

## Зона расклада — пять карт

### Геометрия определяется архетипом

Архетип вычисляется через `detectArchetype()` в `scoring.js`. Четыре варианта геометрии:

---

#### Архетип А — «Что происходит» / W-форма, якорь в центре

```
[2]       [3]
    [1]         ← якорь
[4]       [5]
```

Карта №1 в центре по горизонтали и вертикали.
Карты 2 и 3 выше и по краям, карты 4 и 5 ниже и по краям.

| Позиция | Роль |
|---|---|
| 1 — центр — якорь | узел всей ситуации |
| 2 — верх левый | поверхность |
| 3 — верх правый | скрытое |
| 4 — низ левый | движение |
| 5 — низ правый | вектор |

---

#### Архетип Б — «Что будет» / 3 сверху + 2 снизу, якорь в центре верхнего ряда

```
[2]  [1]  [3]
      ↑
    якорь
  [4]   [5]
```

Верхний ряд: три карты, якорная в центре.
Нижний ряд: две карты по центру под якорем.

| Позиция | Роль |
|---|---|
| 2 — верх левый | было |
| 1 — верх центр — якорь | сейчас |
| 3 — верх правый | между |
| 4 — низ левый | фактор |
| 5 — низ правый | исход |

---

#### Архетип В — «Что делать» / Пирамида сверху вниз, якорь сверху

```
      [1]        ← якорь
   [2]   [3]
   [4]   [5]
```

Три ряда, центрированные.
Карта №1 одна сверху по центру.
Под ней два ряда по две карты.

| Позиция | Роль |
|---|---|
| 1 — верх центр — якорь | что держит |
| 2 — второй ряд левый | корень |
| 3 — второй ряд правый | ресурс |
| 4 — третий ряд левый | шаг |
| 5 — третий ряд правый | знак |

---

#### Архетип Г — «Кто этот человек» / Крест, якорь в центре

```
      [2]
       |
[4] — [1] — [3]   ← якорь в центре
       |
      [5]
```

Классический крест. Карта №1 в центре.

| Позиция | Роль |
|---|---|
| 1 — центр — якорь | человек |
| 2 — верх | лицо |
| 4 — лево | мотив |
| 3 — право | природа |
| 5 — низ | исход |

---

### Визуал карт

**Все карты показываются лицом — иллюстрации видны сразу.**

**Якорная карта №1:**
- Размер: на ~15–20% крупнее остальных карт
- `box-shadow: 0 0 12px rgba(201,168,76,0.35)`
- `border: 2px solid var(--gold)`

**Остальные карты (2–5):**
- Стандартный размер
- Стандартная рамка
- Никаких номеров, никаких меток

**Номера позиций на картах не показывать.**

**Область тапа каждой карты: минимум 44×44pt.**
Особенно важно для расклада на 5 карт — карты меньше по размеру чем в раскладе на 3.

---

### Анимация появления карт

1. Якорная карта №1 появляется первой: `fade-in + scale 0.95 → 1`, длительность `0.5s`
2. Пауза `~0.6s`
3. Карты 2, 3, 4, 5 появляются по порядку с интервалом `~0.4s` каждая

`easing: cubic-bezier(0.25, 0.46, 0.45, 0.94)`

---

### Состояния карты

| Состояние | Вид |
|---|---|
| Якорная — всегда | Крупнее + золотая акцентная рамка + свечение |
| Нетронутая | Стандартный вид |
| Активная (в момент тапа) | `box-shadow: 0 0 18px rgba(201,168,76,0.5)` |
| Просмотренная | Без изменений — не приглушать |

## Блок «Духи леса шепчут»

Идентичен блоку на экране 3 карт. Располагается **сразу под зоной расклада**.

Блок использует тот же ритуальный принцип, что и `ТВОЙ ВОПРОС`: **тонкая золотая черта слева**, без карточки и тяжёлого контейнера.

**Текст:**

```
│ Духи леса шепчут:
│
│ Первый образ задаёт тон.
│ Второй показывает то, что влияет на путь.
│ Третий слой отвечает из тени.
│ Четвёртый знак показывает движение.
│ Пятый собирает линию в одно направление.
│
│ Что теперь просит твоего шага?
```

- Левая черта: `2px solid var(--gold)`, как в блоке `ТВОЙ ВОПРОС`
- «Духи леса шепчут:» — первая строка, `color: var(--gold)`, `font-style: normal`, `font-weight: 500`
- Текст — короткие смысловые строки, `font-style: italic`, `color: var(--text-primary)`
- Перед финальной строкой/вопросом нужен отдельный отступ
- `font-family: var(--display-font)`, `font-size: 14px`, `line-height: 1.8`
- Выравнивание: по левому краю
- `margin: 0 20px`, `padding-left: 12px`
- Никакой рамки, никакого фона, никакой подложки — только золотая черта

Текст строится функцией `buildPositionAwareOracleMessage` из `oracle-local.js`.
Голос строит одну историю через все пять карт — от корня к знаку. Не называет позиции карт. Выводится не сплошным абзацем, а короткими смысловыми строками: до 5 строк по картам + финальная строка/вопрос.

Финал текста меняется по архетипу:
- Архетип А → заканчивается вопросом-зеркалом
- Архетип Б → заканчивается знаком, утверждением о времени
- Архетип В → заканчивается командой
- Архетип Г → заканчивается предупреждением или вопросом

## CTA

На экране 5 карт нет перехода к следующему раскладу. Только завершение.

**Основная кнопка:**

```
[ ЗАДАТЬ НОВЫЙ ВОПРОС ]
```

- Возврат к колоде, сброс сессии
- `background: transparent`
- `border: 1px solid rgba(201,168,76,0.4)`
- `color: var(--gold)`
- Полная ширина с отступами `0 14px`
- `padding: 15px`, `border-radius: 8px`
- `font-size: 11px`, `letter-spacing: var(--tracking-ritual)`, `font-weight: 600`

Кнопка использует роль `final outline gold`: те же ширина, padding, радиус, размер и трекинг, что у основных CTA, но без золотой заливки. Расклад завершён, поэтому действие заметное, но тише кнопок раскрытия.

## Состояние B — Modal card (App Store-style)

### Триггер

Тап на любую карту в раскладе → открывается modal overlay с деталями этой карты.

Экран расклада сохраняет scroll position, все карты, текст духов и завершённые анимации. Это не отдельный route.

### Анимация открытия

- Expand transition из позиции карты в раскладе
- `duration: 0.4s`, `cubic-bezier(0.32, 0.72, 0, 1)`
- Фоновое затемнение: `background: rgba(0,0,0,0.75)`

### Содержимое modal card (сверху вниз)

```
                            [×]

[иллюстрация карты — крупно]

   ✦ КЛЮЧЕВОЕ СЛОВО ПОЗИЦИИ ✦

       Название карты

   ─────── ПОСЛАНИЕ ───────
   Текст послания (2–3 предложения)

   ─────── ТЕНЬ ───────
   Текст тени (1 предложение)
```

**Кнопка закрытия:**
- Верхний правый угол
- Область тапа: минимум 44×44pt, визуально 28×28px круг
- `border: 0.5px solid rgba(255,255,255,0.15)`, иконка ×

**Ключевое слово позиции:**
- Берётся из `archetype-config.js` для текущего архетипа и номера позиции
- `font-size: 8px`, `letter-spacing: 3px`, `color: var(--gold)`, sans-serif, uppercase

**Иллюстрация:**
- Реальное изображение из assets
- `max-height: 45vh`, `object-fit: contain`
- Без рамки внутри modal

**Название карты:**
- `font-family: var(--display-font)`, `font-size: 22px`, `text-align: center`

**Послание:**
- `font-size: 15px`, `line-height: 1.75`, `text-align: center`, `padding: 0 28px`

**Тень:**
- `font-size: 13px`, `font-style: italic`
- `color: var(--text-muted)`, `text-align: center`, `padding: 0 32px`

### Закрытие

- Кнопка × сверху справа
- Тап на затемнённый фон
- `Escape` (для браузера / веб-версии)
- После закрытия — возврат к раскладу без потери состояния

### Навигация между картами

Свайпа между картами нет. Чтобы посмотреть другую карту — закрыть modal и выбрать другую в раскладе.

## Что не делать

- Не показывать подписи позиций на картах в раскладе — только внутри modal card
- Не нумеровать карты — ни цифрами, ни кружками
- Не приглушать просмотренные карты
- Не добавлять свайп между картами в modal
- Не использовать bottom sheet — только App Store expansion
- Не добавлять шеринг на этот экран
- Не создавать отдельный route для просмотра карты
- Не делать кнопку «ЗАДАТЬ НОВЫЙ ВОПРОС» золотой заливкой — только `final outline gold`
- Не добавлять кнопку «Выйти» или «Закрыть приложение»
- Не выравнивать текст «Духи леса шепчут» по центру — только по левому краю
- Не оформлять «Духи леса шепчут» как карточку, рамку или панель с фоном — только левая золотая черта
