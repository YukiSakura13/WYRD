# Project Brief: WYRD

## Позиционирование

**WYRD — атмосферный цифровой оракул духов леса: человек задаёт вопрос, получает символический знак и углубляет его в расклад 1→3→5, чтобы увидеть нынешний узор и выбрать следующий шаг, а не получить предсказание неизбежного будущего.**

Полный утверждённый контракт первой беты: [TELEGRAM_BETA_SCOPE.md](TELEGRAM_BETA_SCOPE.md).

## Формат продукта

- одностраничный frontend на HTML/CSS/JavaScript без сборщика;
- mobile и desktop Web/PWA;
- Telegram Mini App через platform adapter;
- local-first состояние с планом versioned storage и синхронизации;
- GitHub Pages как текущий production Web-контур;
- ограниченная бесплатная beta-когорта до отдельного go/no-go.

## Основная ценность

WYRD создаёт короткий, атмосферный и понятный ритуал символической рефлексии. Он помогает увидеть действующий сейчас узор и следующий возможный шаг, не выдавая художественный ответ за неизбежное предсказание или профессиональный совет.

## Основной цикл

**onboarding → вопрос → 1 карта → 3 карты → 5 карт → текстовый Голос Оракула → След → возвращение**

Существующие Дары поддерживают возвращение, но не превращаются в сложную экономику в первой бете.

## Текущий baseline

Уже реализованы cover, ритуальное знакомство, вопрос в свободной форме, runtime-набор 74 карт, чтения 1/3/5, локальный Голос Оракула, Следы/Дары, история, share, звук, PWA и базовые smoke/accessibility-проверки.

Главные незавершённые зоны MVP: канонизация контента, одноразовый first-run onboarding, полная responsive/platform QA, versioned state/offline recovery, Telegram adapter/backend, безопасный AI endpoint с fallback, privacy/analytics и release gates.

## Продуктовые границы

- весь цикл 1→3→5 остаётся бесплатным в первой бете;
- paywall, Stars, платежи и TTS не блокируют MVP;
- новые карты, режимы и сложная мета-игра ждут beta evidence;
- Лес не ставит диагнозы, не даёт юридических/финансовых решений и не обещает исход;
- accessibility, responsive, ясные ошибки и web fallback обязательны.
