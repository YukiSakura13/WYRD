Что убрано

Нет огромных ромбов, чужих заливок, декоративной звезды в поле ввода и новых рамок, которых нет в текущем приложении.

Правило

UI Kit показывает язык компонентов WYRD, а не придумывает новый экран. Любой следующий вариант сверяется с реальными кнопками, полями и строками приложения.

Локальная доска для проверки компонентов перед переносом в runtime. Сначала форма и поведение, потом декоративность.
