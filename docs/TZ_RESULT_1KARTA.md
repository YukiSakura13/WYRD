## Два объекта: Reading Screen и Share Card

Это разные объекты с разными требованиями. Не смешивать.

### A. Reading Screen — экран внутри приложения

Интерактивный экран. Пользователь читает, взаимодействует, прокручивает.

- Может быть длинным (карта + крючок + CTA)
- Содержит все кнопки (шеринг, CTA, назад)
- Атмосфера важна, но читаемость важнее
- Анимация появления карты при загрузке экрана
- Работает на тёмном фоне приложения (`var(--color-bg-base)`)

### B. Share Card — карточка для репоста

Статичный визуальный объект. Генерируется через `html2canvas`.

- Только кремовый блок карты: рамка + иллюстрация + название + послание + тень
- Никаких кнопок, никакого UI приложения
- Пропорции: вертикальный прямоугольник ~3:4
- При генерации PNG: разрешение 2x (`scale: 2`) для чёткости на retina-экранах

**Правило:** UI не обрезает текст. Если текст слишком длинный для красивой Share Card — это проблема контента, не UI.

---

## Поведение при длинном тексте (overflow)

### Иллюстрация

Высота адаптивная: `min-height: 200px`, `max-height: 320px`, `object-fit: contain`.
Изображение вписывается целиком без обрезки. Текст никогда не влияет на высоту иллюстрации.

### Послание

- Текст не обрезается — отображается полностью
- Длиннее 3 строк → уменьшить font-size до 13px, line-height до 1.6
- Длиннее 5 строк → уменьшить до 12px

### Тень

Аналогично посланию. При длинном тексте уменьшить шрифт до 10px.

### Карта в целом

- Карта растёт в высоту вместе с текстом — нет фиксированной высоты контейнера
- Скролл появляется на уровне **экрана**, не внутри карты
- Весь экран (включая крючок и CTA) доступен при прокрутке вниз
- Карта никогда не обрезается снизу — пользователь всегда видит завершающий ✦

### Маленькие экраны (< 360px ширина)

- Padding внутри карты: `10px 20px` вместо `12px 32px`
- Название карты: 15px вместо 18px
- CTA-кнопка остаётся неизменной

## ЗОНА 1 — Навбар и вопрос

### Навбар

Три элемента в ряд: кнопка назад / логотип / пустой спейсер.

**Кнопка назад (слева)**
- Круглая кнопка, 36×36px
- Фон: прозрачный
- Граница: `1px solid var(--accent-12)`
- Иконка: стрелка влево, `stroke: var(--gold)`, stroke-width 1.5

Блок отображается всегда. Содержимое зависит от наличия вопроса.

**Декор (общий)**

## ЗОНА 2 — Карта

Карта — единый визуальный объект на кремовом фоне, который шерится как изображение.

```
1. Иллюстрация
2. Название карты
3. Послание
4. Тень
+ PNG-рамка поверх всего (z-index 2)
```

### Контейнер карты

- Background: `rgba(242, 235, 221, 1)` — кремовый пергамент
- Border-radius: 12px
- Margin: 0 14px
- Overflow: hidden
- Position: relative

### Декоративная рамка карты (PNG overlay)

Рамка — PNG-файл с прозрачным фоном, наложенный поверх карты.

**Почему PNG, а не SVG:**
`html2canvas` нестабильно рендерит SVG с тонкими линиями. На Share Card рамка может поплыть или исчезнуть. PNG overlay даёт 100% одинаковый результат и в приложении, и в экспортированном изображении.

**Файл рамки:** `assets/images/card-frame.png`
- Экспортируется один раз в разрешении 2x (для retina)
- Содержит: двойной прямоугольник, угловые звёзды-компасы, `WYRD` вверху по центру, крупная звезда внизу, ромбы по бокам
- Цвет элементов: `#8b6914` на прозрачном фоне

**Описание рамки для дизайна/экспорта:**
- Внешний прямоугольник: stroke `#8b6914`, stroke-width 0.8, отступ от края 6px
- Внутренний прямоугольник: stroke `#8b6914`, stroke-width 0.4, отступ от внешнего 5px
- Угловые звёзды-компасы (все 4 угла): четырёхлучевые, длинные лучи ~11px, короткие ~7px, opacity 0.9
- Верх центр: текст `WYRD` 7px + горизонтальные линии и точки по бокам
- Низ центр: крупная звезда-компас ~14px + ромб под ней
- Середины боковых сторон: ромб + точка сверху и снизу, opacity 0.6

**CSS наложения:**
```css
.card-frame {
  position: absolute;
  inset: 0;
  width: 100%;
  height: 100%;
  object-fit: fill;
  mix-blend-mode: multiply;
  pointer-events: none;
  z-index: 2;
}
```

**Важно для html2canvas:** `useCORS: true`, `allowTaint: false`, `scale: 2`.

### 1. Иллюстрация

- Занимает всю ширину карты
- Фон: `rgba(242, 235, 221, 1)`
- Высота: `min-height: 200px`, `max-height: 320px`, `object-fit: contain`
- Изображение: `card.image`

### 2. Название карты

- Border-top: `1px solid rgba(139, 105, 20, 0.3)` — разделитель арт/текст
- Padding: 14px 20px 8px
- Text-align: center

**Русское название**
- `card.name`
- Шрифт: `var(--ui-font)`, 18px, `letter-spacing: 0.12em`
- Цвет: `#1a1710`
- Margin-bottom: 8px

**Английское название — не используется.** `card.subtitle` на этом экране не отображается.

**Декоративный разделитель после названия**
- Тонкая линия с ✦ по центру
- Линии: `background: #8b7340`, height 0.5px, opacity 0.35
- Символ: `#8b7340`, opacity 0.35

### 3. Послание

- Padding: 12px 32px 8px
- Text-align: center

**Лейбл ПОСЛАНИЕ**
- `var(--ui-font)`, 8px, `letter-spacing: var(--tracking-ritual)`
- Цвет: `#7a5c20`, opacity 0.9
- Display: block, margin-bottom: 8px

**Текст послания**
- `card.message`
- `var(--display-font)`, 14.5px, line-height 1.7
- Цвет: `#1e1a0e`

### 4. Тень

- Padding: 10px 32px 16px
- Text-align: center
- Border-top: `0.5px solid rgba(201, 161, 74, 0.2)`
- Margin-top: 10px

**Лейбл ТЕНЬ**
- `var(--ui-font)`, 7.5px, `letter-spacing: var(--tracking-ritual)`
- Цвет: `#8b7340`, opacity 0.55
- Display: block, margin-bottom: 6px

**Текст тени**

- `var(--display-font)`, 11px, italic, line-height 1.6

## Кнопка шеринга

Расположена снаружи карты, сразу под ней.
Margin: 0 14px, Padding: 12px 0

**Вид**
- Иконка шеринга + текст `ПОДЕЛИТЬСЯ КАРТОЙ`
- Иконка: `stroke: #6e6040`, 11×11px
- Текст: `var(--ui-font)`, 9px, `letter-spacing: 0.18em`, цвет `#6e6040`
- Выровнено по центру, gap 7px, фон прозрачный

**Поведение при нажатии**

1. `html2canvas` захватывает DOM-элемент карты: `useCORS: true`, `allowTaint: false`, `scale: 2`
2. Генерируется PNG в разрешении 2x
3. `navigator.share({ files: [imageFile] })` — нативный шеринг
4. Fallback: скачать PNG через `<a download>`

**Важно:**
- Старый механизм шеринга (отправка текста) удалить полностью
- Брендирование `WYRD` остаётся только в рамке карты
- Кнопка шеринга — только одна, только под картой

## Состояния шеринга

Шеринг должен быть понятным для пользователя на каждом этапе. Нажатие на кнопку не должно выглядеть как “ничего не произошло”.

### Базовый сценарий

При нажатии на кнопку `ПОДЕЛИТЬСЯ КАРТОЙ`:

1. UI переходит в состояние генерации изображения
2. `html2canvas` захватывает DOM-элемент карты
3. Генерируется PNG в разрешении 2x
4. Если устройство поддерживает `navigator.share({ files })` — открывается нативный шеринг
5. Если нативный шеринг файлов недоступен — PNG скачивается автоматически

### Состояние `loading`

Пока генерируется изображение:

- Кнопка шеринга временно disabled
- Повторные нажатия игнорируются
- Текст кнопки меняется на `ПОДГОТАВЛИВАЕМ КАРТУ...`
- Иконку можно скрыть или заменить на спокойный индикатор состояния
- Состояние должно длиться только на время генерации PNG

**Важно:** в состоянии `loading` экран не прыгает, layout не меняется, карта остаётся на месте.

### Состояние `native share`

Если `navigator.share({ files })` доступен:

- После успешной генерации PNG открывается системное окно шеринга
- После закрытия системного окна кнопка возвращается в обычное состояние
- Если пользователь отменил системный шеринг, это не считается ошибкой и не требует алерта

### Состояние `download fallback`

Если `navigator.share({ files })` недоступен, но PNG успешно создан:

- Выполняется автоматическое скачивание PNG
- После запуска скачивания кнопка возвращается в обычное состояние
- Дополнительный alert или toast не обязателен

### Состояние `error`

Если PNG не удалось сгенерировать:

- Кнопка возвращается в обычное состояние
- Пользователь видит короткое понятное сообщение:
  - `Не удалось подготовить изображение. Попробуй ещё раз.`
- Сообщение должно быть визуально спокойным и не перекрывать карту
- Повторная попытка шеринга разрешена сразу

### Что считается ошибкой

Ошибка шеринга — это:

- не удалось загрузить `html2canvas`
- `html2canvas` завершился с ошибкой
- `canvas.toBlob()` вернул `null`
- файл не удалось подготовить для нативного шеринга

Отмена системного окна шеринга пользователем ошибкой не считается.

### Что нельзя делать

- Не возвращаться к старому механизму текстового шеринга
- Не показывать несколько конкурирующих способов шеринга одновременно
- Не оставлять кнопку без визуального отклика после нажатия
- Не позволять многократные нажатия во время генерации PNG

### Техническое правило

Старый механизм шеринга текста удалить полностью.

Единственный объект шеринга на этом экране:
- PNG, сгенерированный из DOM-элемента карты
